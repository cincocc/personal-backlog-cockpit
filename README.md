# 个人需求舱

把共享研发任务池收成你这周要设计的清单。

公司任务池在钉钉多维表里，视图是全员共用的，软件需求、缺陷、硬件固件挤在一张表。你改不了表结构，也不该把真实数据推到公网。这个工具只在你这台电脑上工作：导入导出的 Excel / CSV，筛出自己的条目，分类、估时、装进本周，改完清单状态后再复制一份回写摘要，回到任务池更新原始状态。

钉钉仍然是唯一的数据源。本应用不写回、不上云、不建后端库。

## 能做什么

1. **导入** — 上传钉钉导出的 `.xlsx` / `.csv`，或先加载内置电子价签样例。
2. **映射** — 把 `任务简述`、`产品负责人`、`任务编号` 等列对上一次；下次同一张表不用重配。
3. **需求池** — 按产品负责人筛「我的」；类型和公司状态联合过滤。可改正来源、类型、优先级和小时。需求编号单独一行，方便双击复制。点详情看导入时的完整原始行。
4. **本周** — 按可用小时自动装箱；钉住的条目带旗帜，容量不够也会留在清单里。清单状态（未开始 / 进行中 / 已完成 / 阻塞）只存在本机，可汇总后复制「待回写任务池」，回去改多维表。

规则会自动猜类型和工时（有任务编号 → 缺陷；产品线含固件 / 硬件 / AP / EPD / LCD → 硬件固件；其余按软件需求），每一条都能改。

## 明确不做

- 不接钉钉 OpenAPI，不写回多维表
- 不做账号、权限、评论、附件
- 仓库和公开演示里不放真实客户或同事数据

## 数据放哪

快照和偏好都在浏览器 `localStorage`：表格内容一份，映射 / 负责人 / 钉住 / 清单状态一份。清空按钮会删掉本机数据。请不要把公司导出的 Excel 提交到 Git；`.gitignore` 已忽略 `*.xlsx`。公开演示只用 `public/samples/esl-backlog.sample.csv`。

更完整的问题边界见 [PRD](./PRD-personal-backlog.md)。

## 本地运行

```bash
npm install
npm run dev
```

打开终端里的本地地址 → **加载样例** → 对上列名 → 选负责人 `Alex Chen` → 在需求池和本周里试用筛选、详情和清单状态。

```bash
npm test
npm run build
```

技术栈：Vite · React · TypeScript · MUI · SheetJS。
